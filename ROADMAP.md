# Evidence-gated roadmap

MotifGuard's roadmap is organized around claims that can be independently
verified. A milestone is complete only when its public evidence is available.

## Completed

- Public, login-free production product.
- Real multimodal analysis with explicit 0-100 score validation.
- Browser-side payload control and graceful HTTP 413 retry.
- Separate 0-100 overall score and 0-1 evidence-confidence contracts.
- Case 02 diagnosis -> revision -> re-audit loop with raw response and hashes.
- Historical Case 03 score-contract defect preserved without retroactive repair.
- Passing CI, contract tests, deployment commit, and artifact provenance.
- Five-minute judge-verification path and explicit claim boundaries.

## Next evidence gates

These are not current product or traction claims.

1. **Independent design review:** a transportation or product designer repeats
   the workflow with their own images and consents to publish the outcome.
2. **Repeat-use evidence:** the same independent user revises a render and
   completes a second audit.
3. **Human baseline:** measure manual review time and finding overlap before
   making any efficiency claim.
4. **Domain expansion gate:** validate a non-automotive creative workflow before
   changing the current automotive-only scope.

No milestone will count developer tests, curated samples, or automated traffic
as users, audience, testimonials, or traction.
